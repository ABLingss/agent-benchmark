# 前端题启动

应用运行只需Python 3.10+与浏览器。当前目录执行 `python serve.py`，打开 http://127.0.0.1:8763 。初始页面只是入口，按 TASK.md 实现。

自动测试的安装必须在正式计时前完成，需要Node.js 20+：

```text
npm ci
npx playwright install chromium
npm test
```

自动测试会自行启动页面服务，运行前关闭手动启动的8763端口服务。初始页面不具备要求的功能，公开验收失败是预期；环境准备是否成功，以浏览器安装和页面可打开为准。

公开测试只覆盖部分行为，面试官还会做删除、临界金额、非法输入、存储损坏、键盘和手机宽度等检查，均来自TASK.md。前端不访问外部服务、不伪造支付；导出是浏览器真实下载的文件。
