Windows / macOS 怎么打包提交？

Windows：右键完成的题目文件夹，选择“压缩为 ZIP 文件”；Windows 10 选择“发送到 → 压缩(zipped)文件夹”。macOS：右键文件夹，选择“压缩”。然后在本页选择生成的 .zip 文件上传。

只打包题目文件夹，不要打包整个工作区。先移除 node_modules、.git、.venv 和缓存，保留代码和资源。支持中文文件夹名。浏览器提交即可，无需安装提交客户端，也不用运行 .command 文件。
