# 本机提交与验收

## 一键启动

Mac 双击仓库根目录的 `启动提交服务.command`。自动打开本机管理页，并在终端显示提交口令。

- 管理页：本机8788端口，需要本次启动自动生成的管理入口。
- 候选人页面：8787端口，只提供上传和本人回执。
- 管理页点“生成外网链接”，通过Cloudflare Tunnel分享候选人页面；或双击 `start-public.command` 同时启动两者。

只把候选人链接和提交口令发给候选人。管理页不通过Tunnel开放。上传成功不会自动执行代码，必须由面试官在本机点“运行测试”。

也可以在仓库根目录运行：

```text
python3 -m submission.server
python3 -m submission.server --tunnel
```

`--no-browser` 可禁止自动打开管理页。端口占用时用 `--port 其他端口 --admin-port 其他端口`；用 `--private-dir` 指定其他位置的面试官包。

## 先放好面试官包

目录应当是：

```text
同一个父目录/
  agent-benchmark/          公共仓库
  agent-benchmark-private/  面试官专用包解压后的目录
```

私有目录包括 `evaluate_gateway.py`、`gateway-contract/`、`gateway_hidden.py`、`frontend_checks/` 等。网关自动验收只需Python 3.10+。前端验收还需Node.js 20+，提前在私有目录运行：

```text
npm ci
npx playwright install chromium
```

管理页显示两题的依赖就绪状态。专用包不在公共仓库中，也不要把它放在候选人提交目录里。

## 候选人怎么交

打开面试官发来的链接，填写姓名/编号、题目和口令，上传ZIP文件。可以压缩对应题目目录，也可以压缩不含依赖的完整项目。

- 网关需保留同目录下的 `router.py`、`proxy.py`、`server.py`。
- 前端需保留同目录下的 `index.html`、`menu.json` 和实现使用的文件。
- 文件最大20MB，解压后最大60MB。不要包含 `node_modules`、`.git`、私有验收包或本机提交数据。
- 保存提交成功后的回执链接，状态会自动更新；一个回执对应一次提交，可以继续上传新版本。

## Windows 候选人提交

候选人可以用 Windows 10/11 上的 Edge、Chrome 或 Firefox 打开提交链接，直接上传，无需安装提交客户端或在自己的电脑启动提交服务。仓库里的 `.command` 文件由面试官在 Mac 上启动服务时使用，候选人不用运行。

1. 保存代码，找到完成的 `gateway` 或 `frontend` 文件夹。先移除其中的 `node_modules`、`.git`、`.venv` 和缓存，保留代码及资源。不要压缩整个工作区。
2. Windows 11：右键该文件夹 → “压缩为 ZIP 文件”（部分版本显示“压缩到 → ZIP 文件”）。Windows 10：右键 → “发送到 → 压缩(zipped)文件夹”。用其他压缩软件时同样选择 ZIP，不选 7z、RAR 或加密压缩。
3. 在提交页填写信息，选中生成的 `.zip` 文件，点“提交作品”。两道题分别上传。
4. 显示提交成功后，复制并保存回执链接。

支持中文姓名、中文文件夹名及 Windows ZIP 路径。网关代码仍需符合题目的 Python 3.10+ 要求；验收在面试官电脑执行，避免写死 `C:\...` 等本机绝对路径。前端资源请随项目打包，文件名大小写与引用一致。

## 面试官怎么验收

1. 本机管理页显示全部提交，点“运行测试”加入本机队列。
2. 一次只验收一份，完成后显示各组通过数和自动分。
3. “详情”可查看完整日志，“下载”可取回原ZIP；“导出结果JSON”保存当前汇总。
4. 自动测试以外的过程、讲解和视觉评分由面试官另行记录。

网关执行专用包内封存的测试；前端由提交服务启动静态页面，执行专用包内的浏览器用例，不运行候选人上传的启动脚本、npm脚本或测试配置。完整日志仅管理页可见，候选人回执显示分组结果与自动分。

这是本场面试的**人工确认后、本机执行**流程，不是面向陌生人自动运行代码的隔离沙箱。只对本场已确认来源的提交点击运行。

## 保存与停止

终端按Ctrl+C关闭服务及由它开启的Tunnel。提交ZIP、数据库、测试报告保存在被Git忽略的 `.submission-data/`；重启仍保留。临时外网地址可能改变，重开后重新复制候选人链接。

若管理页提示登录失效，用本次启动时终端显示的“本机管理入口”重新打开。若Tunnel无法连接，可在管理页重开，或自行运行：

```text
cloudflared tunnel --url http://127.0.0.1:8787
```

## 服务自身测试

在仓库根目录运行 `python3 -m unittest discover -s submission/tests -v`。
